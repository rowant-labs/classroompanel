ClassroomPanel / Product North Star

The AI tutor with a living blackboard.

ClassroomPanel helps students learn by turning questions, notes, PDFs, and course material into one adaptive visual learning space. It does not just answer. It teaches, draws, simulates, quizzes, and adjusts.

The core idea

A student should be able to say, “I don’t understand derivatives,” and watch the panel become the lesson: graph, tangent line, explanation, animation, practice problem, and feedback — all on one board.

Conversational tutor Visual canvas Interactive simulations Adaptive checks

MVP wedge

Upload a PDF/chapter/syllabus → generate an interactive blackboard lesson.

  • Start with one subject area where visuals matter.
  • Render reliable components instead of arbitrary images.
  • Use quizzes to detect confusion and re-teach.

Why it can win

Most AI study tools are chat boxes. Most LMS products are file cabinets. ClassroomPanel is the live teaching layer between them.

Rendering strategy

The model should not freehand everything. It should plan lessons into a structured visual DSL that our app renders safely and beautifully.

  • graph for math/function plots
  • diagram for labeled concepts
  • simulation for step-by-step interaction
  • quiz for checks and feedback
  • notes for concise explanations

Build plan

  1. Prototype the board: static landing page + one polished interactive lesson demo.
  2. Define the lesson schema: JSON blocks for graphs, diagrams, cards, checks, and state transitions.
  3. Add the tutor loop: student prompt → lesson plan → rendered board → quiz → adaptation.
  4. Support uploads: PDF/text ingestion that turns source material into a board lesson.
  5. Save/share sessions: students can resume panels and send them to classmates/parents/tutors.
